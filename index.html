About StoreVerse

A Modern Multi Shop Management Platform

StoreVerse is designed to help multiple shop owners create and manage their own online stores from a single platform. Every registered owner receives an independent storefront while sharing the same professional ecosystem.

This project is developed as part of the Web Programming Lab curriculum using semantic HTML5 and external CSS. Future versions will integrate JavaScript, AJAX, TypeScript and Angular as the syllabus progresses.
